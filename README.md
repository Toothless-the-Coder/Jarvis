# Jarvis
This will be an ai assistant that runs on a pi zero two, it will use cloud computing whenever possible to run the ai, but will also have a local backup protocol just in case. Jarvis' case features a three piece design, the top piece is nothing but a top and a speaker mesh, it keeps it looking nice and allows the sound through, the middle part holds the speaker itself, it has holes for heatset inserts to be used to thread in screws to mount the speaker, the bottom piece holds all the electronics, this is where the pi, amp, and microphone live, there are slots in the sides of this part for air to naturally flow in and carry away the heat, no fans though, as the electronics shouldn't make all that much heat. The code is in principle fairly simple, just take what the user says and send it off to an ai then speak the response, but it is actually quite a complex problem to solve, as speech to text is not exactly an easy thing.
